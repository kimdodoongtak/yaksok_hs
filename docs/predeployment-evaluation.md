조사일: 2026-11-17, Asia/Seoul. 이 프로젝트의 기록을 요청한 9개 평가 기준과 대조했다. 다른 모델·프로젝트와의 우열 비교는 아니다. 이번 조사는 기록과 로그를 읽었으며 앱 테스트를 새로 실행하지 않았다.

**평가 범위**

이 시점에는 000 기반, 001~009 및 004a, 빨강 티켓 UI, Neon 연결이 반영되어 있었다. 010 카카오 실제 연동은 미구현이었다. 011 홈 생성(`96dbaac`), 설정 단계 스크롤 보완, 운영 성능 개선, 모바일 시간표 후속 수정은 이후 커밋이므로 평가에서 제외했다. 따라서 최초 배포 당시에는 일반 사용자가 홈에서 약속을 만드는 진입점도 없었다. 검증용 링크는 서버 발급 서비스를 통해 만들었다.

**시간·토큰 집계 방법**

로컬 `/Users/Iris/.codex/sessions` JSONL에서 `session_meta.cwd`가 프로젝트 루트와 정확히 같은 기록을 읽었다. 이벤트 시각이 종료점 이하인 기록만 집계했다. 이 조건의 이벤트가 있는 로그 파일은 주 대화 13개, 자동 승인 검토 41개였다. 이어진 대화에서 복제된 과거 기록을 포함하므로 파일 수를 독립 개발 작업 수로 보지 않는다.

주 대화의 `token_count.info.total_token_usage` 전체 필드 조합으로 반복 이벤트를 제거한 뒤 `last_token_usage`를 합산했다. 보조 세션은 세션 ID와 누적 카운터 조합으로 중복을 제거했다. 완료 시간은 `turn_id`별 `task_complete.duration_ms`를 한 번씩 합산했고, 실제 구간의 합집합도 별도로 계산했다. 사용자 메시지는 `client_id`, 없으면 턴 ID와 항목 ID로 중복을 제거했다.

| --- | ---: | ---: | ---: | ---: | ---: |
| 주 대화 | 368,211,226 | 360,094,976 | 8,116,250 | 1,347,286 | 369,558,512 |
| 자동 승인 검토 | 64,608,842 | 59,952,640 | 4,656,202 | 89,226 | 64,698,068 |
| 합계 | 432,820,068 | 420,047,616 | 12,772,452 | 1,436,512 | 434,256,580 |

로그의 주 대화 모델 식별자는 `gpt-6-astra`, `gpt-5.6-sol`, 자동 승인 검토 식별자는 `codex-auto-review`다. 단일 모델의 개발 결과로 단정하지 않는다. 최초 주 대화 시작 기록은 2026-11-12 23:50:29 KST로, 첫 Git 커밋보다 늦다. 따라서 집계는 프로젝트 전 생애의 AI 사용량을 보장하지 않는다. 로그에 기록되지 않은 작업은 포함하지 못한다.

기존 [개발 지표](development-metrics.json)는 009 커밋 또는 2026-11-15 오후 스냅샷까지여서 배포 전 전체 집계로 사용하지 않았다. 기존 파일은 수정하지 않았다. 이번 집계는 종료점의 초 이하 시각도 엄격히 적용했으며, 기존 009 집계와 대조 시 합계 토큰 69,209개 차이가 있었다. 기존 집계 스크립트가 없어 그 차이의 원인을 확정하지 않았다. 두 집계를 섞어 증분을 계산하지 않는다. 이번 결과와 집계 조건은 [별도 JSON](predeployment-metrics.json)에 보존했다.

공통 환산 단가를 비캐시 입력 `P입력`, 캐시 입력 `P캐시`, 출력 `P출력`의 100만 토큰당 가격으로 정하면, 자동 승인 검토 포함 환산 비용은 다음과 같다.

`12.772452 × P입력 + 420.047616 × P캐시 + 1.436512 × P출력`

주 대화만 비교한다면 `8.116250 × P입력 + 360.094976 × P캐시 + 1.347286 × P출력`이다. 모델별 실제 비용을 구하려면 모델별 사용량과 해당 시점 청구 단가·청구 내역을 추가 대조해야 한다. 현재 단가를 임의로 적용하지 않았다.

**평가 판단**

초대 링크가 제공된 이후의 핵심 웹 흐름에는 자동 테스트와 실제 DB 검증 근거가 있다. 다만 최초 배포 범위에는 일반 사용자의 생성 진입점이 없었고, 최종 코드 전체 회귀·실기기 사용성·공통 요구사항 채점이 갖춰지지 않았다. 따라서 기록이 뒷받침하는 평가는 **“핵심 흐름 구현 및 관련 검증 완료, 배포 전 제품 전체 완성도는 부분 확인”**이다.

현재 비교용 수치로 재사용하기 좋은 것은 범위를 명시한 토큰 집계와 완료 턴 실행시간이다. 요구사항 충족률·UI 점수·잔여 결함 등급·사람 노동시간·휴식 제외 개발시간·교정 개입 횟수는 추가 측정 없이는 수치화하지 않는다.
