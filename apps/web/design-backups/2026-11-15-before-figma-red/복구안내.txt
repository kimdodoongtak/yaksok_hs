Figma 빨강 디자인 적용 전 기준 백업

기준 커밋: e804d375c3b745dbf73810d94f65f47bade73e7e
현재 실행 앱의 소스는 이 커밋과 동일합니다. 아직 Figma 새 디자인을 앱에 적용하지 않았습니다.

current-app.zip: 현재 앱의 UI·스타일·이미지·서버 소스·패키지 잠금 파일·설정.
figma-design-work.zip: 커밋하지 않은 로컬 디자인 시안, 생성 스크립트, 상태 기록.
manifest.json: 파일 목록과 SHA-256 해시, 디자인 관련 파일 경로(ui_paths).

나중에 “2026-11-15-before-figma-red 기준으로 원래 앱 디자인을 복구해줘”라고 요청하면 됩니다.
디자인만 복원할 때는 current-app.zip을 별도 임시 폴더에 풀고 ui_paths 목록을 현재 소스와 비교합니다.
이후 추가된 기능이 있다면 전체 앱을 덮어쓰지 않고 UI 변경만 골라 복원합니다.
전체 앱 소스까지 이 시점으로 돌아가려면 current-app.zip의 apps/web/가 기준입니다.
복원 뒤 Docker Node.js 24에서 변경 범위에 맞는 검증을 실행합니다.

실제 환경 변수·DB 데이터·설치된 패키지·빌드 결과물은 포함하지 않았습니다.
Figma 작업 ZIP은 로컬 파일 백업이며 클라우드 Figma 원본 파일의 내보내기는 아닙니다.
이 백업은 현재 컴퓨터에 저장했으며 원격 업로드·커밋·푸시는 하지 않았습니다.
ZIP 무결성과 각 원본 파일의 SHA-256 일치를 확인했습니다.
