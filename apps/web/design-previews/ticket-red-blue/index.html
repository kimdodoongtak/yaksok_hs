YAKSOK / DESIGN STUDY 02

약속을 기다리는 티켓.

보내준 레퍼런스를 바탕으로 같은 5개 화면을 빨강과 파랑으로 비교했어요. 따뜻한 종이색, 검정 본문, 짧은 설정 행과 절취선 티켓을 공통으로 사용합니다. 화면을 누르면 원본 크기로 볼 수 있어요.

VERMILION RED

티켓과 도장의 경쾌한 인상

01 / 약속 설정

날짜·시간·소요 시간·정원·마감을 요약 행으로 편집.

배치 제안 · 입력 규칙은 유지하고, 상세 편집은 별도 패널로 여는 제안.

필수 기능 · 모집 시작 전 서버 검증 · 초안 10분 · 정원 2~30명

02 / 초대 링크

초대 티켓과 링크 복사, 가능 시간 입력 진입.

배치 제안 · 기본 공유 시트·복사로 연결. 카카오 연동을 뜻하지 않음.

필수 기능 · 설정 요약 · 복사 성공/실패 · 닉네임·PIN 참여 안내

03 / 가능 시간

1시간 기본 보기, 드래그, 주 반복·초기화·되돌리기.

배치 제안 · 시간표만 내부 스크롤하고 하단 제출바는 고정.

필수 기능 · 30분 단위 저장 · 명시적 제출 · 전체/개인 시간 비교

04 / 시간 후보

후보 선택을 강조하고 하단 확정 버튼으로 연결.

배치 제안 · 확정 전 확인창 유지. 일반 참여자에게 확정 버튼 없음.

필수 기능 · 소요 시간 전체 공통 2명 이상 · 인원↓/시작 시간↑ 정렬

05 / 확정 티켓

기차 사진·절취선·도장·참석자·결과 링크 복사.

배치 제안 · 공유 결과는 참여자 로그인 후에만 공개.

필수 기능 · 복사 실패 시 수동 복사 · 방장만 재조율 · 도장 모션 유지
