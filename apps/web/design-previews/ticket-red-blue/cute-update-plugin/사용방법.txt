약속행 · 남은 도장/확정창 적용

이 파일은 Figma MCP 한도로 직접 반영하지 못한 디자인을 적용하는 개발 플러그인입니다.
Figma 실행은 미검증입니다. 문법 검사는 별도 상태 기록을 확인하세요.

대상 파일: https://www.figma.com/design/ZjcFr02Eo3878EKLEVhNgc
적용: 미니 티켓 확정 확인창, 결과 티켓 확정 도장, 취소/만료/잘못된 링크/탈퇴 도장.
이미 반영된 동물 말풍선의 얼굴 크기와 행 높이도 정리합니다.

1. Figma 데스크톱에서 대상 파일을 엽니다.
2. Plugins → Development → New plugin에서 실행 1회형 개발 플러그인을 생성합니다.
3. 생성된 폴더의 code.js를 동봉한 code.js로 바꿉니다.
4. Figma가 만든 manifest.json의 id는 유지하고, 나머지 설정은 manifest-settings.json에 맞춥니다.
5. Plugins → Development에서 해당 플러그인을 실행합니다.

다른 파일 또는 예상 레이어가 없는 파일에서는 실행을 중단합니다.
네트워크 통신은 하지 않습니다. 실제 앱 코드를 바꾸지 않습니다.
완료 문구 후 확정 확인창을 선택합니다. 변경은 Figma 실행 취소로 되돌릴 수 있습니다.
중복 실행은 차단합니다. 실행 중 오류가 났다면 반복 실행 전에 적용 상태를 확인하세요.
