티켓 디자인 제안 / 빨강·파랑

상태: 로컬 시안 작성. Figma 도구 호출 한도로 기존 파일 직접 추가는 미완료.
대상: https://www.figma.com/design/PsUT7wTtMLlOyTuDaDqljN

1. 바로 보기
index.html을 브라우저로 엽니다. 빨강·파랑 탭으로 비교할 수 있습니다.
화면을 누르면 원본 SVG가 열립니다.

2. SVG로 가져오기
ZIP을 푼 뒤 필요한 SVG를 Figma 캔버스에 드래그합니다.
이 방법에서는 텍스트가 벡터로 변환될 수 있습니다.

3. 편집 가능한 텍스트·컴포넌트로 가져오기 (Figma 실행 미검증)
Figma 데스크톱에서 위 파일을 열고 로컬 개발 플러그인을 새로 만듭니다.
Figma가 생성한 manifest.json의 고유 id를 유지하고, main을 code.js로 설정합니다.
editorType은 ["figma"], documentAccess는 "dynamic-page",
networkAccess는 {"allowedDomains":["none"]}으로 설정합니다.
동봉한 figma-code.js를 플러그인 폴더의 code.js로 복사한 뒤 실행합니다.
새 페이지 ‘제안 02 · 티켓 Red / Blue’를 추가합니다. 기존 화면은 수정하지 않습니다.
반복 실행하면 별도의 페이지와 변수가 추가됩니다.
사진은 파일 안에 포함되어 있습니다. 외부 네트워크 요청은 없습니다.
공식 manifest 안내: https://developers.figma.com/docs/plugins/manifest/

포함: 393×852 화면 5종×2색상, 구성요소 시트 2종,
색상 변수, 상태별 버튼·시간 칸 컴포넌트, 화면별 필수 기능 설명.
약속행 이름, 요약 행 편집, 시간표 내부 스크롤은 디자인 제안입니다.
기존 앱의 동작을 변경한 것이 아닙니다. 전체 오류·모달·로그인 화면 리디자인은 포함하지 않습니다.

검증 (2026-11-15): Docker Node.js 24에서 스크립트 문법 확인, Chromium에서 10개 화면 이미지 로드·화면 밖 텍스트 없음 확인, 빨강/파랑/비교 전환 확인, 393px 미리보기 문서 가로 넘침 없음. 빨강·파랑 전체 화면 시각 검수. Figma 내부 실행은 호출 한도로 미검증. 정적 디자인 제안이므로 제품 TDD 대상 아님.
