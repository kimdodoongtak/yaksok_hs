# 006 마감 버튼과 후보 화면 분리

- 2026-11-15 사용자 요청: 마감 버튼과 후보를 보려면 긴 시간표 아래로 내려가야 하는 문제를 해결한다.
- 합의: 방장 마감 버튼은 고정 상단 오른쪽, 마감 후 후보 전용 화면, 필요하면 응답 시간표로 돌아가 비교한다.
- 변경: `/candidates` 추가. 수동 마감·기한 경과·다른 기기 마감 확인 시 후보로 이동한다. `/availability?view=responses`는 읽기 전용 시간표로 유지하며 상단에서 후보로 돌아간다. 참여 정보에서도 마감 상태는 후보로 연결한다.
- 보호: 기존 인증·방장 권한·확정 서버 재검증을 재사용한다. 모집 중 후보 주소는 시간표로, 확정 후에는 티켓으로 이동한다. DB 모델과 후보 계산 변경 없음.
- 실제 RED/GREEN과 후속 회귀 결과: [006 TDD 기록](../tdd/006-confirmation.md).
- 검증: 후보 기본 진입 실패를 먼저 확인한 뒤 같은 테스트를 통과했다. 전체 Chromium 52개·린트·타입 검사 exit 0. 320/393/1280px 화면과 고정 상단·시간표 왕복을 검수했다.
- 운영 빌드 exit 0. 정식 feature 검토는 후속이며 커밋·푸시·배포는 수행하지 않았다.
