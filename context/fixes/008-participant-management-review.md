## R1 · P3 · 조회가 복구되어도 실패 안내가 남음

- 위치: `apps/web/src/components/participants/participants-panel.tsx:30`, `:35`.
- 재현: 참여자 관리 화면에서 `/participants/state` 요청을 한 차례 차단해 실패 안내를 띄운다. 차단을 해제하고 같은 명단으로 정상 조회를 두 번 완료한다.
- 실제 Chromium 확인: 두 응답이 HTTP 200·`ok: true`인데도 **“최신 정보를 불러오지 못했어요. 잠시 후 다시 확인할게요.”**가 계속 표시된다.
- 원인: 실패 안내와 일반 알림을 같은 `message`에 저장하고, 정상 조회에서는 snapshot이 달라질 때만 message를 바꾼다. 연결만 복구되고 명단·상태가 동일하면 기존 실패 안내가 해제되지 않는다.
- 영향: 데이터 변경·인증에는 영향이 없지만, 연결이 복구된 화면을 계속 조회 실패 상태로 오해하게 한다. 참여자 변경이나 페이지 새로고침 전까지 남는다.
- 보완 방향: 조회 실패 상태를 일반 안내와 구분하고 최신 유효 조회가 성공하면 실패 상태만 해제한다. 승계·내보내기 안내까지 매 조회마다 지우지 않도록 한다.
- 후속 구현 시 기대 동작인 ‘복구 후 오류 안내 해제’를 실패 테스트로 먼저 확인한다. 이번 재현은 결함이 남는지를 관찰한 사후 검증이며 수정의 RED/GREEN으로 소급하지 않는다.
