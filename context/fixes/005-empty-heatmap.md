# 005 빈 히트맵 표시 수정

- 2026-11-15 사용자 지적: 빈 시간까지 0을 반복 표시해 참고 이미지의 빈 시간표 표현과 달랐다.
- 원인: 집계가 0이어도 숫자를 그대로 렌더링했다. 앞선 시각 검수에서 발견하지 못했다.
- 수정: 가능 인원이 1명 이상인 칸에만 숫자를 표시한다. 0명은 빈 칸이며 기존 색상 단계·서버 계산·접근성 안내를 유지한다.
- 실제 RED/GREEN과 모바일 캡처 검수는 [005 TDD 기록](../tdd/005-status-and-candidates.md)의 해당 항목에 기록했다.

## 후속 사용자 결정 — 전체 색상 히트맵

- 숫자 반복 표시를 아예 없애고 일반 슬롯은 색상만 표현하도록 변경했다. 실제 소요 시간 전체의 공통 참석자 2명 이상인 후보만 시간·인원 라벨을 표시한다.
- 주간 임시 후보를 조회 응답에 추가했다. 모집 중 공식 후보 목록은 여전히 노출하지 않는다.
- 축소 보기의 동일 칸에 여러 시작 후보가 있으면 대표 후보 라벨을 누르면 전체 후보를 확인한다. 원래 교집합·순위 정책은 그대로다.
- 실제 DB·브라우저 RED/GREEN과 상세 창 초점/지연 close 보정 근거는 TDD 기록에 이어 남겼다.
