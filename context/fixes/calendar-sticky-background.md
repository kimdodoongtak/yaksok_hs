# 스크롤 시 상단 메뉴의 네모 배경

최신 상태: 2026-11-25 전체 브라우저 125/125 통과. 모바일 스크롤 후 둥근 모서리와 노트북 높이·정렬을 실제 캡처로 검수했다. 아래 미검증·로컬 보류는 당시 이력이며 [최종 검증 기록](../tdd/settings-calendar-release.md)을 따른다.

2026-11-25 사용자 스크린샷 피드백. 로컬 CSS 수정.

- 모바일 상단 메뉴는 좌우 margin 16px 안쪽에만 배경을 그려, 흰색 시트가 아래로 지나갈 때 양옆에 흰색이 드러나고 메뉴 배경이 네모 조각처럼 보였다.
- 메뉴 바의 배경은 페이지 양끝까지 늘리고, 기존 버튼 위치는 내부 padding 24px로 유지한다. 기존 페이지 padding 8px와 메뉴 margin 16px의 합과 같다.
- 높이·고정 위치·버튼 크기·문서 스크롤 및 노트북 배치는 유지한다. 기존 만료 링크 버튼 변경도 보존한다.
- 정적 CSS 수정으로 TDD 비대상. diff 공백 검사만 수행했으며 브라우저·실기기 검수, 테스트 실행, 커밋·배포는 아직 하지 않았다.

## 후속: 위로 스크롤해도 둥근 모서리 유지

- 사용자 요청으로 고정된 날짜·조작부 뒤에 페이지 배경을 먼저 덮고 그 위에 둥근 흰색 배경을 그리도록 변경했다. 아래에서 올라오는 흰색 카드 본문이 모서리를 채워 네모처럼 보이지 않게 한다.
- 모바일 28px·노트북 20px의 기존 곡률과 좌우 폭을 유지한다. 배경 레이어는 포인터 입력을 받지 않으며 조작부 위치·높이·스크롤 방식은 바꾸지 않는다.
- 로컬 CSS 반영과 diff 검사만 완료. 브라우저·실기기 검수와 커밋·배포는 미실행이다.
