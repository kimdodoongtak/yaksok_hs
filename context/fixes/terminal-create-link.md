# 만료·취소 링크에서 새 약속 진입

최신 상태: 2026-11-25 전체 브라우저 125/125 통과. 만료 화면의 홈 링크·약속 상세 비노출 회귀와 320px 유효하지 않은 링크 화면의 터치→홈 이동을 확인했다. 아래 로컬 보류는 당시 이력이며 [최종 검증 기록](../tdd/settings-calendar-release.md)을 따른다.

2026-11-25 사용자 요청. 로컬 적용.

- 만료·취소·유효하지 않은 링크의 공통 안내 아래 `새 약속 만들기` 링크를 버튼 형태로 제공한다.
- `/`의 기존 생성 화면으로 이동한다. 클릭만으로 약속을 생성하거나 기존 약속을 다시 열지 않는다.
- 버튼 최대 너비 240px·최소 높이 48px, 기존 파란 강조색과 키보드 포커스 스타일을 사용한다.
- 기존 001 AC-6, 003 AC-4, 009 AC-4의 ‘안내만 표시’에 공개 홈 이동 링크를 허용하는 후속 변경이다. 약속 상세·참여자·입력·결과 비공개와 API 접근 차단 정책은 유지한다. 유효한 링크의 작성 시간 만료는 기존 재등록 흐름을 유지한다.
- 정적 링크·CSS 추가로 TDD 비대상이다. 기존 만료 회귀의 ‘링크 없음’ 기대값은 새 링크 1개와 홈 목적지를 확인하도록 갱신하고 상세 정보 비노출 검사는 유지한다. 이번 변경의 테스트 실행·실기기 검수·커밋·배포는 하지 않았다.
