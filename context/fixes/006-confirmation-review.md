## 추가 결정·구조 검토

- 모집 중 고정 상단 마감, 마감 후 `/candidates`, 명시적 `/availability?view=responses` 왕복과 읽기 전용 유지, 확정 후 result 이동을 코드와 브라우저 기대값으로 대조했다. 이전 테스트 변경은 승인된 화면 이동을 반영하며 읽기 전용 검증을 제거하지 않았다.
- 기차 사진·SEE YOU SOON·빨간 CONFIRMED 도장과 충격 모션은 사용자 승인 범위다. 날짜·시간·참석자와 공유 동작을 유지한다. 장식 바코드와 SVG 도장은 개인정보·토큰을 담지 않는다.
- CSS 애니메이션은 안정된 요소에서 한 번 실행하고 폴링으로 재마운트하지 않는다. `prefers-reduced-motion`에서는 애니메이션을 끈다. 직전 일회성 브라우저 검수의 갱신 후 재생 없음·축소 화면 가로 넘침 없음 근거를 확인했다.
- DB/비밀값 접근은 `server-only` 서비스에 남고, 클라이언트에는 결과 DTO만 전달한다. 기존 DB 제약·5개 마이그레이션을 재사용한다. 신규 의존성·운영 변경 없음.
- 후보 없음 이후 재조율/취소 연결은 기존 005의 후속 범위인 007/009로 남긴다. 이번 검토에서 아직 만들기로 하지 않은 실행 기능을 결함으로 간주하지 않았다.
