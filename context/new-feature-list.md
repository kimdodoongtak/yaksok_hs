# 기능 스펙 목록

2026-11-06 기준, 제공된 PRD·ERD·참고 이미지로 MVP 제품 스펙 10개를 작성했다. 전체 근거·흐름·화면·충돌·미정 사항은 [분해 계획](spec-plan.md)에 기록한다. 사용자 결정에 따라 PRD와 ERD가 충돌하면 ERD를 우선한다.

제품 스펙 상태는 문서 준비 상태와 실제 구현 상태를 구분한다. 2026-11-12 현재 기능 000의 최소 앱 구현과 대체 검증을 마쳤고, 2026-11-13 요구사항 검토와 최종 검증을 마친 뒤 사용자 요청으로 000을 완료 처리했다. 이후 001 제품 기능과 단위·DB·브라우저 테스트를 추가하고 두 차례 검토 발견사항을 TDD로 보완했으며 최종 요구사항 검토와 전체 회귀 후 같은 날 완료 처리했다.

000 앱 기반과 001 초대 링크 접근·방장 등록은 완료했다. 001은 2026-11-13 `feature 시작` 요청에 따라 TDD 구현과 검증을 수행하고 두 차례 검토 발견사항도 보완했다. 재검토에서 확인한 AC-3 U+2800 비가시 문자와 선점 링크의 해시 비용 경계는 RED→GREEN 처리했고 최종 요구사항 검토와 전체 회귀 후 완료했다. 001의 닉네임·초안 세션·링크 만료 정책은 같은 날 사용자 결정으로 확정했다. 이후 마감 변경·재조율 세션 갱신 등 후속 기능의 정책은 해당 기능 전에 확인한다. 미제공 비즈니스 규칙·API 문서를 임의로 재현하지 않는다. 추가 자료가 오면 원본 대응표를 기준으로 갱신한다.
