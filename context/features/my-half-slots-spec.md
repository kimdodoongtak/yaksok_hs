# 내 시간 30분 부분 선택 표시

2026-11-25 사용자 요청. 상태: 구현·검증 완료. 후속 모서리 피드백까지 반영했고 관련 브라우저 76/76, 단위 56/56, 린트·타입·빌드·diff 검사를 통과했다. 커밋·푸시 후 운영 배포를 확인한다.

- 1시간 보기에서 앞 30분만 선택됐으면 위 절반, 뒤 30분만 선택됐으면 아래 절반을 기존 선택색으로 칠한다. 칸의 ‘일부’ 문구와 사선 무늬는 제거한다.
- 두 절반 모두 선택되면 기존 전체 선택·연결 표시를 유지한다. 30분 보기와 마지막 30분짜리 칸도 기존 표시를 유지한다.
- 1시간 보기의 탭/키보드/드래그 선택 단위와 저장 데이터는 바꾸지 않는다. 표시용 절반은 포인터 이벤트를 받지 않는다.
- 접근성의 mixed 상태와 버튼 이름을 유지하고 실제 선택한 30분 구간을 설명한다. 범례는 절반 색칠과 ‘30분 선택’으로 맞춘다. 날짜 보기의 일부 가능 요약은 변경하지 않는다.
- 320px·1280px에서 위/아래 선택 위치·동일 높이·구별되는 색, 단위 전환·키보드·제출 결과를 브라우저로 검증하고 기존 터치 회귀를 확인한다.
- 후속 스크린샷 피드백: 반 칸을 큰 외곽선 안에서 잘라 표현하지 않는다. 내 시간의 빈/선택 반 칸은 각각 네 모서리를 둥글게 하고 사이에 2px 간격을 둔다. 전체 시간의 빈 반 칸도 선택 영역에 맞닿는 모서리를 둥글게 한다. 같은 칸의 두 빈 반 칸은 하나로 합치고, 선택된 연속 구간은 기존 연결을 유지한다.

서버·DB 변경 없음. [검증 기록](../tdd/my-half-slots.md).

## 2026-11-25 후속 시안 — 한 시간 칸 안에서 분할

사용자가 내 시간의 독립된 둥근 반 칸 대신 1시간 칸 하나를 반으로 나누도록 요청했다. 내 시간 mixed 칸의 외곽선과 둥근 모서리를 하나로 유지하고 안쪽 두 절반은 간격 없이 맞붙인다. 중앙 구분선과 기존 선택색으로 앞/뒤 30분을 구분한다. 1시간 전체 터치 영역과 선택·저장 동작은 유지한다. 전체 시간의 연속 구간은 이번 범위에서 변경하지 않는다. 정적 CSS 시안으로 TDD 비대상, 로컬만 수정한다.
