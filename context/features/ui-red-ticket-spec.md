- [x] AC17(2026-11-16 사용자 요청): 마감을 오늘 기준 1주 뒤(기본)·2주 뒤·직접 선택으로 변경한다. 신규 선택은 해당 날짜 23:59이며 시간 입력을 없앤다. 약속 시작일을 바꿔도 기본 마감은 오늘 기준, 직접 고른 마감은 보존. 마감 이후 소요 시간이 남지 않는 빠른 선택/날짜는 차단하고 선택 가능한 날이 없으면 약속 종료일 변경 안내. 기존 저장된 마감 시각은 사용자가 다시 고르기 전까지 보존한다. AC14/15의 마감 UI·기본값 기준을 대체한다.
