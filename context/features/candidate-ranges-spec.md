# 연속 후보와 참석 가능 명단

2026-11-25 사용자 요청. 상태: 로컬 구현·검증 완료. 기존 로컬 색상 변경·데모 데이터는 보존하고 로컬에서 구현·검증한다.

- AC1: 공식 ‘가능한 약속 시간’ 목록은 같은 참석자 집합의 연속된 시작 후보를 하나의 가능 구간으로 묶는다. 09~13시 내내 같은 사람들이 가능하고 소요 시간이 2시간이면 09~11/09:30~11:30 등을 반복하지 않고 09~13 후보 하나를 표시한다.
- AC2: 같은 인원수라도 참석자가 다르면 합치지 않는다. 날짜 경계·불가능한 시작점의 간격도 넘지 않는다. 기존 active·제출 완료·미래·최소 2명·소요 시간 전체 교집합 기준을 유지한다.
- AC3: 묶음 기준 인원 내림차순·시작 오름차순으로 정렬하고 묶은 뒤 5개/더 보기를 적용한다. 주간 히트맵 및 서버 확정 시 유효 시작점 검증은 유지한다.
- AC4: 방장·참여자 모두 후보의 날짜/시간 영역을 누르면 그 구간 전체에 참석 가능한 닉네임 명단을 펼치고 닫을 수 있다. 명단은 서버가 계산한 참석자 ID와 인증된 동일 응답의 공개 참여자 목록으로 표시한다. 주간 조회 범위 밖의 공식 후보도 정확한 명단을 제공한다.
- AC5: 방장은 명단 영역과 구분된 ‘이 시간 선택’으로 확정 창을 연다. 구간이 소요 시간보다 길면 구간 안의 30분 단위 시작 시간을 고르고, 실제 확정 범위는 설정된 소요 시간으로 표시/저장한다. 후보 클릭이나 시작 선택만으로 제출하지 않는다.
- AC6: 폴링으로 후보가 사라지거나 참석자가 바뀌면 열린 명단도 최신 후보를 따른다. 최종 확정은 기존 서버가 시점·참석 가능 여부·방장 권한을 재검증한다.

계산 단위 RED/GREEN, 격리 DB의 범위/페이지/인증·명단 확인, 브라우저 펼침·접기·모바일 터치·시작 선택·실제 확정으로 검증한다. 색상/간격은 TDD 비대상이며 캡처로 검수한다. DB 스키마 변경 없음. [검증 기록](../tdd/candidate-ranges.md).

2026-11-25 후속: 고정 길이 확정 창은 사용자 승인으로 후보 전체 기본 선택·시작/종료 업다운 조절로 확장했다. AC5의 실제 확정 길이는 설정값 이상이며 후보 범위 안에서 선택한다. [최신 스펙](adjustable-confirmation-spec.md)을 따른다.
