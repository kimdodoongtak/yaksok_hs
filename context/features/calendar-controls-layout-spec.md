# 시간표 조작 영역 재배치

- 상태: 구현·검증 완료 — 2026-11-20
- 기준: 배포된 `3d9cf9e` 화면. 이미지 A 전체를 구현하지 않고 사용자가 다시 지정한 배치를 적용한다.
- 사용자 최신 지침: 로컬 검증 후 커밋·푸시하고 자동 배포를 확인한다.

## 수용 기준

1. 되돌리기·복구 버튼을 제거하고 그 위치에 스크롤/선택 전환을 둔다. 30분·1시간·2시간은 오른쪽에 계속 노출한다. 터치 기본 스크롤·선택 모드·PC 입력·제출 보존은 유지한다.
2. 메뉴 아이콘만 내 시간·전체 시간 탭 옆에 배치한다. 모바일 탭은 화면 중앙에 두며 메뉴로 약속 정보에 접근한다. 상단 별도 마감 줄은 없앤다.
3. 남은 응답 시간은 제출 버튼 바로 옆 하단에 표시한다. 방장 응답 마감 버튼은 메뉴와 같은 상단 줄의 오른쪽에 표시한다. 일반 참여자에게는 마감 버튼이 없다. 마감 뒤 후보 이동과 전체 시간 보기에서도 남은 시간/마감 상태에 접근한다.
4. `이번 주 반복`을 `주간 반복`으로 바꾸고 초기화 진입 버튼을 그 창 안에 둔다. 빈 주에서도 창을 열어 다른 주를 포함한 전체 초기화에 접근할 수 있다. 빈 패턴의 반복 적용은 금지하며 안내한다.
5. 초기화는 기존 현재 주/전체 범위를 명시적으로 선택한다. 취소·Escape는 값을 바꾸지 않고, 지난 시간과 다른 주 보존·제출 전 DB 미저장·동시 갱신 때 창 닫기를 유지한다. 되돌리기 제거에 맞춰 복원 가능 안내도 제거한다.
6. 320·393·1280px에서 겹침·가로 넘침 없이 조작하고, 스크롤 뒤에도 메뉴·날짜·마감·제출에 접근한다. 하단 마감 영역과 선택 드래그의 자동 스크롤 경계를 확인한다.

## 검증과 범위

- AC4~5: 새 진입·빈 주 초기화 흐름을 브라우저 RED→GREEN으로 검증한다.
- AC1~3: 제거된 동작의 테스트를 요구사항 변경에 맞춰 정리하고 새 배치·권한별 노출·선택/제출을 검증한다. 정적 배치는 TDD 비대상으로 실제 캡처·브라우저 배치 검사로 확인한다.
- 되돌리기/복구 전용 테스트는 제품 동작 제거에 따라 폐기하고, 혼합 테스트의 데이터 보존·제출·초기화·반복 검증은 유지한다.
- Docker Node.js 24에서 관련 Chromium·단위·린트·타입·빌드. 서버·DB 정책·핀치·하루 전체 선택·후보 계산은 변경하지 않는다.

- 결과: AC1~6 구현·검증 완료. 실행 차이와 미검증 환경은 [TDD 기록](../tdd/calendar-controls-layout.md)을 따른다.
