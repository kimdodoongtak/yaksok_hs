# 설정 시간 직접 입력

상태: 구현·검증 완료. 2026-11-25 후속 요청으로 다른 로컬 UI 변경과 함께 전체 회귀 검증·배포 범위에 포함했다. 최종 시간 칸은 높이 64px, 라벨/숫자 간격 3px, 라벨 묶음 위 패딩 4px이다. [전체 검증·배포 기록](../tdd/settings-calendar-release.md)을 따른다. 아래 기준은 유지한다.

- AC1: 시작/종료 숫자 영역을 탭하면 숫자 키패드가 열리는 text 입력을 제공한다. `9`, `930`, `0930`, `09:30`을 입력할 수 있고 blur/Enter 때 유효한 값은 HH:mm으로 표시한다.
- AC2: 시작 00:00~23:30, 종료 00:30~24:00 및 30분 단위를 유지한다. 잘못된 값·빈 입력은 조용히 반올림하거나 이전 값으로 제출하지 않고 안내하며 다음 단계에서 기존 검증으로 차단한다.
- AC3: 소요 시간의 시간/분 숫자 칸을 각각 직접 편집한다. 30분~24시간, 분은 00/30을 허용한다. 하루 시간대보다 긴 소요 시간은 기존 폼/서버 검증이 차단한다.
- AC4: 화살표는 기존대로 30분 조절하며 직접 입력과 같은 값을 반영한다. 잘못된 입력 중 화살표를 누르면 마지막 유효값에서 조절한다. Enter는 다음 단계로 넘어가지 않고 편집만 확정한다.
- AC5: 모바일 입력 글꼴 최소 16px, 숫자 칸의 기존 굵기·높이·접근성 이름/오류 연결을 유지한다. 날짜·시간대·소요 시간·다음 버튼의 393×700 최초 노출 회귀를 확인한다.

입력 파싱·범위는 단위, 실제 키보드/단계 전환/제출 데이터 연결은 격리 DB 브라우저로 검증한다. 정적 스타일은 TDD 비대상. 서버·DB 정책 변경은 없다. [실행 기록](../tdd/settings-direct-time.md).
