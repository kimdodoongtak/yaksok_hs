# 날짜 단위 가능 시간 선택

- 상태: 구현·검증 완료 — 2026-11-20
- 기준: main `69370df`, 작업 트리 깨끗함. 사용자 승인: 2시간 대신 날짜 보기, 하루 선택·해제, 일부 가능, 시간 보기와 선택 공유.

## 수용 기준

1. 입력 단위를 `30분 | 1시간 | 날짜`로 표시한다. 기본은 1시간이며 날짜 보기에서는 시간 축 대신 한 달의 날짜를 요일에 맞춘 7열의 작은 네모 칸으로 표시한다. 날짜 보기에서는 월 이동, 시간 보기에서는 주 이동을 제공한다.
2. 날짜 카드는 탭/클릭/키보드로 방장이 설정한 하루 범위의 미래 30분 슬롯을 전체 선택·해제한다. 일부 선택은 나머지를 채운다. 날짜 화면은 별도 스크롤/선택 전환 없이 탭으로 조작하고 스와이프는 스크롤한다.
3. 선택 안 함/일부 가능/전체 가능을 구별한다. 시간 보기 복귀·월/주 이동·전체/참여자 보기 전환에도 미제출 선택을 유지한다. 설정한 시간 범위를 명시하고 오늘은 남은 시간만 변경한다. 지난 시간과 범위 밖 날짜는 변경하지 않는다.
4. 날짜 보기에서도 주간 반복·초기화·명시적 제출·제출 실패 보존·외부 갱신·마감 권한을 기존 정책대로 유지한다. 마감 뒤에는 읽기 전용이다.
5. 전체 시간의 날짜 카드는 해당 하루 범위 전체를 제출한 공통 참여자 수와 일부 시간만 제출한 참여자 수를 구분한다. 시간별 최대 인원을 하루 전체 인원으로 오인하지 않도록 실제 참여자 교집합을 사용한다. 개별 참여자 보기도 읽기 전용 요약이며 조회 중/실패는 미조회 표시한다.
6. 320·393·1280px에서 겹침 없이 조작하며 날짜 전환 시 긴 시간표의 스크롤 위치에 갇히지 않는다. 상단 메뉴·방장 마감·하단 남은 시간·제출 배치를 유지한다.

7. 추가 사용자 요청: 시간표 선택 모드의 칸 사이 가로·세로 여백도 인접 칸의 선택 영역으로 처리한다. 안쪽에서 시작한 드래그는 페이지 스크롤이 되지 않으며 바깥 여백·시간축 및 스크롤 모드의 스크롤은 유지한다.
