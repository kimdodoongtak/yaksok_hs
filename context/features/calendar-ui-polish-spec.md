# 시간표·약속 정보 UI 정리

2026-11-24~25 사용자 로컬 피드백을 반영한 최종 범위. 상태: 구현·검토·검증 완료, 사용자 요청에 따라 커밋·배포 진행. Docker 단위 51/51·DB 94/94·브라우저 122/122, 린트·타입·스키마·운영 빌드 통과. [근거](../tdd/calendar-ui-polish.md).

## 수용 기준

1. 전체 글꼴은 로컬 나눔스퀘어라운드 400/700/800과 동봉 라이선스를 사용하고 본문·보조색·강조색의 대비를 정리한다.
2. 시간 행은 42px, 보이는 선택 칸은 36px로 줄인다. 1시간 시간축은 `9:00`처럼 시작 시각을 표시하고 선택 범위·접근성 이름·30분 데이터 단위는 유지한다. 히트맵 연결 구간도 같은 행 높이에 맞춘다.
3. `조작 방법`, `시간 선택 단위` 제목과 스크롤/선택 아이콘을 제공한다. 버튼 높이 36px, 단위 30분/1시간/날짜, 기본 터치 스크롤·명시적 선택 전환을 유지한다. 스크롤 글자 오른쪽 여백과 두 묶음 사이 공간을 확보한다.
4. 모바일은 메뉴·보기 탭·마감 줄 아래 하나의 흰색 시트에 날짜·조작부·시간표·제출부를 담는다. 끌어올리기·접기·내부 스크롤은 추가하지 않는다. 노트북은 공통 상단 줄 아래 일정 정보와 시간표 카드 시작선을 맞추고 세로 공간을 확보한다.
5. 약속 정보는 일정/참여자/내 참여 정보의 흰색 카드로 묶고 일정에 파란 헤더·명확한 날짜·설정/초대 링크를 배치한다. 모바일 메뉴와 데스크톱 사이드바의 정보·동작은 동일하다.
6. 스크롤이 손가락 접촉부터 시작해도 선택되지 않고, 선택 모드에서는 칸 가장자리·여백을 포함한 탭/드래그로 편집할 수 있다. 미제출 값·제출·읽기 전용·집계·주간 반복·마감·재조율의 기존 정책은 보존한다.
7. [첫 방문 안내](calendar-coachmarks-spec.md)의 도입·5단계·재실행·브라우저별 종료 기억을 제공한다.

## 범위와 검증

사용자가 철회한 단일 선택 버튼·친구 시간 토글·드래그로 시트 확대는 적용하지 않는다. 기존 서버/DB 정책과 의존성은 변경하지 않는다.

정적 CSS·글꼴은 TDD 비대상이며 화면 검수·반응형/스크롤 회귀로 확인한다. 코치마크와 오류 수정의 실제 RED/GREEN 및 기존 동작 사후 검증은 [코치마크 기록](../tdd/calendar-coachmarks.md)에 있다. 전체 린트·타입·빌드·단위·격리 DB·브라우저 최종 결과는 [UI 배포 검증 기록](../tdd/calendar-ui-polish.md)에 남긴다.
