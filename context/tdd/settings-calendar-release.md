## 실행 결과

Docker Node.js 24, 격리 테스트 DB `sdd_test`를 사용한다. 개발 데모·운영 데이터는 변경하지 않는다.

- `npm run test`: exit 0, 56/56.
- `npm run test:integration`: exit 0, 94/94.
- `npm run lint`: exit 0. 마지막 JSX 정리와 테스트 이름 갱신 후 다시 실행해 통과.
- `npm run typecheck`: exit 0.
- `npm run db:validate`: exit 0.
- `npm run test:browser`: exit 0, 125/125 (4.2분). 스크롤·선택·넓은 접촉 면적/가장자리 터치, 안내 자동 표시/종료 기억, 설정 직접 입력·저장·오류, 초대/권한/취소/확정·재조율 회귀 포함.
- 로컬 320px 모바일 별도 확인: 유효하지 않은 링크에서 `새 약속 만들기`를 탭하면 홈으로 이동. 생성 제출은 하지 않음.
- 화면 캡처 직접 확인: 320px 설정 직접 입력, 393×700 설정 첫 화면, 393px 모집 설정·전체 시간·스크롤 후 둥근 카드·메뉴 여백, 노트북 캘린더 전체 높이·안내. 새 입력칸 숫자/라벨 잘림과 가로 넘침 없음.
- `docker compose exec -e INVITATION_BROWSER_TEST=1 tools npm run build`: exit 0. 로컬 개발 서버와 출력 디렉터리를 분리해 운영 빌드 완료.
- `git diff --check`: exit 0.
- `npm audit --json`: exit 1, 기존과 같은 11개(중간 8, 높음 3), 치명적 0. 높은 항목은 Prisma 개발 도구의 effect 의존성 및 이를 사용하는 패키지다. 자동 수정 제안이 Prisma 6으로의 주 버전 변경을 포함해 이번 UI 배포에서 강제 적용하지 않았다. Next·ESLint 계열 중간 경고도 별도 의존성 정비가 필요하다.

자동 터치 검증과 실제 기기 검증을 구분한다. Chromium 터치 에뮬레이션을 사용하며 실제 휴대전화 키패드·Safari 실기기는 미검증이다.

## 배포 절차

위 검증 결과와 변경 파일을 main에 커밋·푸시하고 연결된 Vercel 운영 자동 배포의 커밋 SHA·READY·공개 도메인 응답을 확인한다. 이 문서는 커밋 직전 기록이며 실제 배포 결과는 완료 응답에서 보고한다. 운영 DB 테스트·초기화·개발 데모 반영은 하지 않는다.
