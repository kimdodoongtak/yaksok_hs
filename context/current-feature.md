## 목표

- [ ] AC-3: 린트·타입 검사·빌드가 통과한다.

## 작업 기준점

2026-11-06 불러오기 시점에 이 폴더는 Git 저장소가 아니어서 HEAD·변경 파일을 확인할 수 없었다. `apps/web/`에는 패키지·Prisma·Next.js 설정 파일이 있고 `src/`는 아직 없다. 기존 파일을 이번 기능의 구현 결과로 간주하지 않는다. 구현 시작 전에 기준점을 다시 확인한다.
