## 목표와 범위

## 수용 기준

- [x] AC-1: closed 약속의 방장만 유효 후보를 선택해 confirmed로 변경할 수 있다. 일반 참여자·미인증·다른 약속 세션은 거절하고 추천 1순위 선택을 강제하지 않는다.
- [x] AC-2: 확정 시 잠금 후 현재 시각·날짜/시간 범위·소요 길이·공통 참석자 2명 이상을 다시 계산한다. 클라이언트의 인원수·순위를 신뢰하지 않는다.
- [x] AC-3: 확정 시작과 confirmed 상태를 함께 저장하고 실패 시 부분 확정이 없다. 종료는 시작+소요 시간으로 계산한다. confirmed에서 소요 시간만 직접 변경하는 요청은 거절한다.
- [x] AC-4: 확정 링크에서 서버의 최신 확정 시간과 허용된 참석자 정보를 보여주며 링크 복사 실패 시 수동 복사를 안내한다. 날짜·시간·참석자 이름은 같은 약속의 active 참여자에게만 인증 후 공개한다. 유효 세션이면 바로 표시하고 세션 만료·새 기기에서는 닉네임·PIN 재로그인을 요구한다. 미인증·비참여자·다른 약속 세션·탈퇴자는 상세 결과를 열람할 수 없다.
- [x] AC-5: 일반 참여자 탈퇴 후에도 확정 시간·상태는 유지하고 참석자만 갱신한다. 2명 미만이 되어도 자동 해제·자동 취소하지 않으며 방장에게 재조율·취소를 안내한다. 실제 탈퇴 연계는 008에서 완성한다.
- [x] AC-6: 모바일에서 후보 선택·확정 중·실패 재조회·확정 결과·링크 공유 상태를 확인한다.
