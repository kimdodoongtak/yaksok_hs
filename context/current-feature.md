# 현재 기능: 003 참여자 등록과 약속별 재인증

## 상태

## 스펙

## 목표

collecting 약속에 친구가 닉네임·숫자 4자리 PIN으로 참여하고, 기존 방장·참여자가 다른 기기에서도 재인증할 수 있게 한다. 여러 기기의 독립 세션과 현재 기기 로그아웃, 정원·마감·접근 제한, PIN 시도 제한 및 현재 PIN 확인을 통한 PIN 변경을 구현한다.

가능 시간 선택·제출은 004, 탈퇴·내보내기 실행은 008, 취소 실행은 009 범위다. 003은 해당 상태를 인증 경계에서 차단하는 기준을 준비한다. PIN 분실·방장 권한 복구와 전역 회원 가입은 제공하지 않는다.

## 수용 기준

- [x] AC-1: collecting·마감 전·정원 여유일 때만 신규 등록한다. 한 자리 남은 정원에 동시 요청이 오면 한 명만 성공한다.
- [x] AC-2: 001의 닉네임·PIN 검증을 재사용한다. 약속별 정규화 닉네임은 유일하며 탈퇴한 닉네임도 재사용하지 않는다.
- [x] AC-3: 정확한 닉네임·PIN의 active 참여자를 재인증하고 여러 기기 세션을 허용한다. 다른 약속의 ID·세션은 사용할 수 없다.
- [x] AC-4: 링크·세션 만료, 현재 역할·참여 상태·약속 상태를 매 요청 검사한다. 링크 만료 안내가 우선하며 유효 링크에서는 인증 부재·만료보다 취소 안내를 우선한다. 로그인 없이 취소 사실만 공개한다. 로그아웃은 현재 세션만 삭제한다.
- [x] AC-5: 같은 약속·정규화 닉네임의 연속 5회 실패 시 5번째 실패부터 10분 차단한다. 로그인 성공 및 차단 종료 시 횟수를 초기화하고 차단 중 재시도로 종료 시각을 연장하지 않는다. 통일된 실패 문구를 제공하고 비밀값을 노출하지 않는다. 별도 IP 방어는 기술 설계에 명시한다.
- [x] AC-6: HttpOnly·운영 Secure·SameSite와 CSRF 방어를 적용한다. 재인증 성공 시점부터 7일간 세션을 유지하며 조회로 연장하지 않는다. 기존 초기 세션·002 연장 정책 및 링크 만료 우선은 유지한다.
- [x] AC-7: PIN 분실·방장 권한 복구를 허용하지 않으며 탈퇴·내보내기 상태의 세션으로 접근할 수 없다. 동일인의 새 닉네임 재가입 완전 차단은 보장하지 않는다.
- [x] AC-8: 등록·재인증·PIN 변경·입력 오류·시도 제한·정원 초과·로그아웃을 모바일·데스크톱에서 검증한다.
- [x] AC-9: 현재 PIN 검증에 성공한 본인만 숫자 4자리 새 PIN으로 변경한다. PIN 해시 변경과 기존 세션 폐기는 원자적으로 처리하고 현재 PIN 검증에도 실패 제한을 적용한다. 현재 PIN과 같은 새 PIN은 거절하고 기존 PIN·세션을 유지한다(2026-11-14 사용자 추가 요청).
